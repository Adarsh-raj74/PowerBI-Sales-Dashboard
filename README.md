# Power BI Sales Dashboard

## Project Overview
This project is an interactive Sales Dashboard created using Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## Key Features
- Total Revenue
- Total Profit
- Profit Margin %
- Total Orders
- Customer Analysis
- Product Analysis
- Interactive Filters
- Drill Through
- Tooltips
- Buttons
